# CRM Fiches d'intervention — Plomberie / Serrurerie / Vitrerie

Application web (installable sur téléphone) pour gérer les fiches d'intervention de votre équipe.

**Pour la mise en ligne : suivez `GUIDE_DE_MISE_EN_LIGNE.md`, étape par étape.**

## Contenu du projet
- `pages/` — les pages de l'application (connexion + CRM)
- `lib/` — logique partagée (connexion à la base de données, listes déroulantes)
- `supabase/schema.sql` — à exécuter une fois dans Supabase pour créer la base de données
- `public/` — icônes et fichier d'installation sur téléphone (PWA)
